# Scripts

- `build_install.sh --host`: run the Go tests, then install `rep` and `rep-host` to `~/.local/bin`.
- `flag_inventory.py BINARY`: count the visible command and flag surface of a built binary.
- `verify/`: real-browser verification harnesses (`verify_*.py`, `verify_interaction.mjs`) and their loopback fixtures; each file's docstring shows its invocation.
- `android/`: device capture helpers.
